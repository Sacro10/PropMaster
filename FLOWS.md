# Frontend Flows

## 3.1 Owner Flow (Happy Path)

Log in as owner -> redirected to Owner Dashboard.

If no properties:

"Create your first property" CTA.

After creating property + units:

Prompt: "Invite tenants" -> open modal to enter tenant email + name.

After tenant invites sent:

Dashboard shows:

- Units w/ tenant status (Invited / Active / Vacant).

Maintenance:

- Owner sees list of tickets (table).
- Can filter by property/status.
- Can override vendor or mark completed.

Billing:

- Sees subscription plan + ability to upgrade/downgrade.
